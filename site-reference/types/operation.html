Metamodel — operation types

Each section below is one operation.<subType>. The Attributes table lists the subtype's own + concern-contributed attributes (provider-tagged); universal documentation attributes are omitted here (see providers.md). Allowed children lists the structural child rules with their cardinality (min..max, * = unbounded).

operation.base

Registry anchor for the attributes every operation shares (ADR-0054): not authorable.

Attributes

Attribute Type Required Default Allowed values Provider Description
@inputRef string no — The object.value this operation takes as its input (ADR-0030). Absent on an operation whose only parameter is the target's borrowed key. Anything other than an object.value is ERR_OPERATION_SHAPE.
@objectRef string no — The entity this operation acts on, declared only when it cannot be derived. It is derived from the input value when its fields extend every primary key field of exactly one entity, each once, else from the output's base entity; an input that borrows part of a key, one key field twice, or the keys of two entities derives nothing, so declare it. Declared and derivable, the two must agree (ERR_OPERATION_TARGET_MISMATCH). It must name an object.entity (ERR_OPERATION_TARGET_UNRESOLVED).
@outputRef string no — The object this operation returns: an object.projection, object.entity or object.value. Which projection a query returns is the author's choice among several over one entity, so it cannot be computed. Anything else is ERR_OPERATION_SHAPE.
@permission string no — The permission name the generated shell asks the project's policy about before anything is written. A key into grant data (who holds it is data, what the policy decides is code), so it is never derived from the operation's name: a rename would silently move access. A dotted identifier path such as purchasing.approve; a package prefix may use :: (ERR_BAD_ATTR_VALUE otherwise). Absent and not @public: the shell uses the derived name <package>.<operation>, with the package of the operation's API, and verify advises or requires an explicit one (setting rules.permissions.names). Several operations may share one.
@public boolean no — The shell calls no permission check. Authentication is the transport's job and is unaffected. Absent means checked. Declaring it with @permission is ERR_PERMISSION_PUBLIC_CONFLICT.

operation.command

A named operation that changes state. Takes an object.value (ADR-0030). Its body is hand-written; the generated shell around it loads the row, checks the permission and the current state, runs the body, and makes the guarded update in one transaction (ADR-0066). Experimental since 1.3.0: the shape may change in a MINOR, including removals and renames (docs/compatibility-policy.md).

When to use: A business action with its own name, input and rules: approve, cancel, transfer. A command that moves a lifecycle names the transitions it may make in @transitions; its body decides which one applies.

operation.query

A named operation that reads. Returns an object.projection (or an entity or value). It changes nothing. Experimental since 1.3.0: the shape may change in a MINOR, including removals and renames (docs/compatibility-policy.md).

When to use: A read with its own name and shape beyond derived get and list: my open requests, the dashboard summary.
