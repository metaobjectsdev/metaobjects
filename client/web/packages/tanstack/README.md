# @metaobjects/tanstack

TanStack runtime for metaobjects: `EntityFetcherProvider`, `<EntityGrid>`, `CellRendererProvider`, and `defaultCellRenderers`. Pairs with `@metaobjects/codegen-ts-tanstack`, which generates `<Entity>.hooks.ts` and `<Entity>.columns.tsx` files that import from this package.

## Install

```bash
pnpm add @metaobjects/tanstack
```
